# DS5110 Homework 2: Tidy, Reshape, Join

This project takes three raw files (quarterly revenue, orders and shipments) and turns them into one tidy table that's ready for analysis.

## How to run

Install the libraries:

    pip install -r requirements.txt

Then open `hw2.ipynb` and click Run All. The notebook runs from top to bottom without any manual steps and saves its results in the `output` folder.

## What's in the repo

- `data/raw/` has the three original files from Canvas. These are never changed.
- `hw2.ipynb` does Steps 0 to 5 in order.
- `output/orders_analysis_ready.csv` is the final table from Step 4.
- `output/step5_raw_vs_tidy.png` is the Step 5 chart, comparing the raw data with the final table.
- `WRITEUP.md` answers each question from the assignment, in order.
